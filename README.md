# Employee Management System – OOP Wrapper

## Project Description
A Python-based Employee Management System demonstrating Object-Oriented Programming (OOP) concepts.

## Features
- Create Person, Employee, Manager, and Developer records.
- Display employee details.
- Implement inheritance and method overriding.
- Use encapsulation with getters and setters.
- Demonstrate `super()` and `issubclass()`.
- Provide a menu-driven interface.
- Load sample records automatically.

## Technologies Used
- Python 3
- Object-Oriented Programming

## How to Run
1. Install Python 3.
2. Download or clone the repository.
3. Open the project folder.
4. Run `python main.py`.
5. Select an option from the menu.
